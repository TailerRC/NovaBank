# NovaBank
NovaBank es una aplicación bancaria web desarrollada con Spec-Driven Development. Parte de requisitos con IDs trazables y criterios de aceptación en Gherkin, usa arquitectura MVC en capas (FastAPI + Jinja2 + MongoDB), y se valida con pruebas unitarias y de integración (pytest), pruebas funcionales end-to-end y análisis de calidad.
